# SabiThink Prototype

A single-page UX prototype for the SabiThink concept.

## Open
Open `index.html` in a browser.

## Prototype flows
- Search-style home dashboard
- Knowledge Tree cards
- Daily Think challenge
- Anti-cramming synthesis notebook
- Root Cause / Leverage Point tagging
- Sandbox preview
- Responsive mobile layout

## Brand direction
Primary: Deep Forest #173B33
Ink: #15211D
Lime Signal: #C8F169
Canvas: #F6F7F4
Secondary blue: #506B8A
Warm evidence accent: #E9A24A

The palette intentionally avoids a stereotypical “school app” look. The lime is used sparingly as a cognitive/action signal rather than as a background colour.
